# Make up

Le QG de Margot pour trouver des missions de maquillage à Paris : cinéma, pub, mode, mariage.

Site : https://hichamovixh.github.io/makeup/

- **Annonces Paris** : les annonces trouvées chaque matin par la veille automatique (fichier `annonces.json`, mis à jour tous les jours vers 7 h).
- **Pistes, Réseau, Agenda, Profil** : enregistrés dans le navigateur de l'appareil utilisé (rien n'est envoyé en ligne).
- **Chercher** : liens de recherche prêts à l'emploi (sites d'annonces, Instagram, Threads, Facebook).
- **Messages** : modèles de candidature et de démarchage.

Le site tient en un seul fichier, `index.html`.
